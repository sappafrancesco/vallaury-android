# Changelog

## 1.0.0

First public release.

- Opens https://app.vallaury.it full screen in a Trusted Web Activity, with a Custom Tab as the fallback.
- Launcher shortcuts: quick note, today's timetable, homework, exams.
- Share target: text shared from any app opens a new note.
- Notifications are handed to the browser (web push), with the Android 13 permission request.
- One permission, no network access of its own, no trackers, backups disabled.
